# Code of Conduct

This repository follows the
[Elixpo Community Code of Conduct](https://github.com/elixpo/elixpo/blob/main/CODE_OF_CONDUCT.md),
which applies to every official Elixpo repository, discussion and event,
including everything related to Google Summer of Code.

Report a concern privately using the reporting steps in that document. Do not
report conduct concerns in a public issue or discussion.
