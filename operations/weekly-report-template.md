# Weekly progress report template

The contributor posts this every week as a comment on the tracking issue for
their project, in the project's repository. Keep it short: links matter more
than prose. The programme coordinator links each report in the public weekly
progress log.

```text
Week N - <idea title>

Done this week
- <what was finished, with links to pull requests or issues>

Next week
- <what you plan to do>

Blockers
- <anything stopping you, and what help you need; or "None">

Plan status
- On track / ahead / behind (one sentence on why)
```

## Notes

- **Blockers** go to the primary mentor straight away as well; the report is
  a record, not the only way to ask for help. See
  [communication.md](communication.md#raising-a-blocker).
- **Plan status** is honest by design. "Behind" is not a failure; it starts
  the conversation described in [evaluation.md](evaluation.md#early-warning).
- Do not include private information about yourself or anyone else.
