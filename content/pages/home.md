## What Elixpo is

Elixpo is an open-source organisation on
[GitHub](https://github.com/elixpo), active since February 2024. The
projects in our ideas list are:

- **[LixBlogs](https://github.com/elixpo/blogs.elixpo)**: a collaborative
  blogging platform with multi-tenant publications, an API and a CLI.
- **[LixSketch](https://github.com/elixpo/sketch.elixpo)**: a collaborative
  canvas for sketches, diagrams and docs.
- **[Crumb](https://github.com/elixpo/crumb.elixpo)**: a self-hosted agent
  harness and terminal, written in Rust.
- **[Elixpo Open Source](https://github.com/elixpo/opensource.elixpo)**: a
  platform, still in development, for running open-source contests and
  mentorship programmes.
- **[Oreo](https://github.com/elixpo/oreo)**: an open MicroPython OS and
  hardware platform for an ESP32-S3 badge.

## Why we want to take part

Google Summer of Code brings new contributors into open source through human
mentorship. That is what we want: one contributor who learns how a real
project works, ships a bounded piece of it with review, and stays involved
afterwards.

## How we have set it up

- Every idea is one problem in one codebase, with explicit "not in scope"
  limits.
- Every idea has a primary and a backup mentor.
- Every idea says how success will be proven, with tests or other evidence
  you can reproduce.
- You can set up each project from a clean checkout without our secrets.
- This site is rendered from one set of Markdown files, so the pages agree
  with each other.
